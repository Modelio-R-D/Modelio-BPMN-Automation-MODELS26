# Reproducing the paper results

This document gives a step-by-step path for an artifact reviewer to reproduce
the quantitative results reported in the MODELS 2026 paper *"Towards
LLM-Assisted Business Process Modeling in an Industrial Modeling Tool"*.

The artifact is structured so that **no LLM access is required to reproduce
the paper tables** — the 6 × 55 runs were executed once at experiment time and
the per-record artifacts (prompt input, generated script, structural metrics,
token counts, execution result) are committed under
[`evaluation/results/raw_jsonl/`](evaluation/results/raw_jsonl/) and unpacked
under [`evaluation/runs/`](evaluation/runs/).

LLM access **is** required only if a reviewer wants to repeat the generation
step (see §3 below).

---

## 1. Reproduce the paper tables (no LLM, no Modelio)

Prerequisites: Python 3.10+, Jupyter, `pandas`, `numpy`.

```bash
pip install pandas numpy jupyterlab
jupyter lab evaluation/results/Evals.ipynb
```

Running all cells reproduces:

- Table 1 — Execution success rates
- Table 2 — Generation time (seconds)
- Table 3 — Token usage and cost per run
- Table 4 — Mean Absolute Error (MAE) by structural dimension
- Table 5 — Generated output size (lines of code)

These map to Tables 6–10 in the paper PDF. The notebook reads only from
[`evaluation/results/raw_jsonl/`](evaluation/results/raw_jsonl/).

## 2. Browse per-scenario artifacts (no Modelio)

For each of the 55 scenarios × 6 (approach, LLM) cells, the artifacts are
extracted as readable files:

```
evaluation/runs/<approach>/<llm>/scenario_<NN>/
    input_scenario.md      # natural-language process description (PMo input)
    ground_truth.bpmn      # ground-truth BPMN XML
    ground_truth.py        # ground-truth Modelio config in BPMN_Helpers format
    generated.py           # the LLM-generated script
    execution_output.txt   # Modelio execution log
    metrics.json           # ground-truth and generated metrics + tokens + timing
```

To regenerate this tree from the JSONL source:

```bash
python tools/extract_runs_from_jsonl.py --clean
```

To inspect, e.g., scenario 07 generated by Claude Opus 4.5 under
Config+Helpers:

```bash
ls evaluation/runs/config-helpers/claude_opus_4_5/scenario_07/
```

## 3. Re-execute a generated script in Modelio (Modelio required)

Prerequisites: Modelio 5.0 or later. See [`INSTALL.md`](INSTALL.md) for setup.

1. Copy [`approaches/config-helpers/BPMN_Helpers.py`](approaches/config-helpers/BPMN_Helpers.py)
   into your Modelio macros folder (path in `INSTALL.md`).
2. Open Modelio, create or open a project, select a package.
3. Open **Views → Script**, paste the contents of any
   `evaluation/runs/.../generated.py`, click **Run**.
4. The generated BPMN diagram appears in the package.

## 4. Re-execute the LLM generation step (LLM API key required)

This step is only needed if a reviewer wants to repeat the generation phase of
the experiment. The exact LLM versions used were:

- Claude **Opus 4.5** (Anthropic API)
- GPT **5.2** (OpenAI / OpenRouter)
- **GLM5** (zai-org via OpenRouter)

LLM settings: see [`evaluation/PROCEDURE.md`](evaluation/PROCEDURE.md) §LLM
settings for temperature, top-p, and retry policy. The system prompts are:

- Config+Helpers: [`evaluation/prompts/system_prompt_config_helpers.md`](evaluation/prompts/system_prompt_config_helpers.md)
- No-Helper: [`evaluation/prompts/system_prompt_no_helper.md`](evaluation/prompts/system_prompt_no_helper.md)

For each of the 55 scenarios in [`evaluation/scenarios/`](evaluation/scenarios/),
send `input_scenario.md` to the LLM with the corresponding system prompt and
capture the response.

## What is *not* in this artifact

- **MATISSE partner materials.** The 24 industrial scenarios from the MATISSE
  project remain confidential. The aggregated structural metrics reported in
  Tables M1–M4 of the paper are documented in
  [`evaluation/matisse/partner_metrics.md`](evaluation/matisse/partner_metrics.md).
- **Manual logic-correctness assessment** is not part of the current artifact.
  Reviewer 1 raised this as future work.
- **Repeated-run variance.** Single-run-per-cell, by design — see
  [`evaluation/PROCEDURE.md`](evaluation/PROCEDURE.md) §Threats.
